# BeastBros Entertainment

Official website for **BeastBros Entertainment** — a media production company providing services from pre-production to post-production.

> **Mission:** Bring every creator to Beast Level.

---

## 🚀 Features

- **Services**: Video Editing, High-CTR Thumbnail & Poster Design, and Retention Scriptwriting.
- **Portfolio**: 16:9 Thumbnail showcase slots with modal enlargement and video editing showcase with integrated player.
- **About Us**: Company origins, executive leadership (Harry, Pritha Roy, Arush Verma), and production crew.
- **Jobs / Recruitment**: Open roster positions (Video Editors, Thumbnail Designers, Poster Designers, Scriptwriters, Minecraft Players, Replay Editors) with direct email application flow.
- **Handles**: Central hub for all official BeastBros and founder YouTube, Instagram, and Discord channels.
- **Contact**: Direct project inquiry form and contact links.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite
- **Styling**: Vanilla CSS (Tailored Black & Red minimal premium design system)
- **Typography**: Google Fonts (*Montserrat* & *Inter*)

---

## 📦 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
